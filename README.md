# 237WebStudio

Landing page for 237WebStudio — we build WhatsApp-selling websites for shops, salons and restaurants in Cameroon.

## Stack
- Single-file HTML + Tailwind CSS (CDN) + Vanilla JS
- No build step. No frameworks. No dependencies.
- Bilingual FR / EN

## Structure
- `index.html` — the entire site
- `images/` — local product, demo and collage photos
- `favicon.svg` — brand icon
